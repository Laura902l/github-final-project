# Simple Interest Calculator

This project is a Bash-based Simple Interest Calculator, created as part of the final project for the "Introduction to Git and GitHub" course.

## About

The `simple-interest.sh` script calculates simple interest based on user input. It prompts the user for three values:

- **Principal amount** – the initial sum of money
- **Rate of interest** – the annual interest rate (%)
- **Time period** – the duration in years

The script then computes the simple interest using the formula:
Simple Interest = (Principal × Rate × Time) / 100

## How to Use

1. Clone this repository.
2. Run the script in a terminal:
```bash
   bash simple-interest.sh
```
3. Enter the requested values (principal, rate, and time) when prompted.
4. The script will display the calculated simple interest.
